# 三阶段玩法（Ver.Mumu 分支）

按队伍草图实现的三个阶段，串在两个锚点之间使用。运行主场景后：

- 按 **5 / 6 / 7** 单独测试某个阶段
- 按 **8** 跑完整流程：吵架 → 扔物大战 → 斗舞 → 召唤电梯怪兽 → 合力打怪 → 和解

## 角色素材

人物直接切 `Assets/Branch/dance.png`（1024×512，4 列 × 2 行，每帧 256×256）：

- **上排 = NPC1（男）**，**下排 = NPC0（女）**，对应 `character_sprite.gd` 里的 `SHEET_ROW`。
- **P1 在左边用 NPC0，P2 在右边用 NPC1**，和对话框里头像的左右位置一致。
- 每帧的落脚线（`FOOT_Y`）和胯部中轴（`PIVOTS`）是量素材得出的。显示时以胯部为轴，
  所以换姿势只有四肢向外伸展，身体不会左右跳；镜像时符号跟着朝向翻。
- 屏幕上身高约 84 像素（`char_scale = 0.34`）。

现有 4 帧的用法（`POSE_FRAME`）：

| 帧 | 内容 | 用在 |
| --- | --- | --- |
| 0 | 站立 | IDLE / RUN / STUNNED |
| 1 | 甩手（男：dab；女：伸手指） | THROW / DANCE_LEFT / DANCE_RIGHT |
| 2 | 抬手 / 转身 | DANCE_UP / CHEER |
| 3 | 收手 | JUMP / DANCE_DOWN / MISS |

**还缺的素材**：跑、跳、被砸眩晕现在都是拿站立帧加代码位移凑的。等专门的动作帧进来，
只要改 `POSE_FRAME` 的映射就能换上，不用动玩法代码。

## 操作

| 玩家 | 移动 | 跳 | 扔 | 跳舞 |
| --- | --- | --- | --- | --- |
| P1（蓝，左） | A / D | W | F | WASD |
| P2（粉，右） | ← / → | ↑ | `/`（或小键盘 0） | 方向键 |

## 阶段一：扔物大战（`Throw/throw_phase.gd`）

- 90 秒倒计时，中间有障碍物隔开两人（跳不过去）。
- 投掷物会自动朝对面当前位置抛一条弧线，站得离墙太近会被墙挡住——需要拉开距离起高抛。
- 砸中对面 **+10 分**，被砸中**眩晕 2 秒**（眩晕期间免疫）。
- 空中随机掉落物品，碰到得分：白球 **+1**、蓝方块 **+3**、金星 **+5**。
- 可调参数（Inspector 或代码顶部）：`duration`、`item_interval`。

## 阶段二：舞蹈对决（`Dance/dance_phase.gd`）

- 上下左右音游，96 BPM，两边谱面完全相同（固定种子生成，公平）。
- 判定：完美 ±0.11s **+5**；还行 ±0.24s **+2**；再宽或漏过记一次「烂」。
- 节拍、判定音效都是代码生成的 8-bit 音，之后可以换成真音乐（改 `BEAT` 对上 BPM 即可）。
- 可调参数：`BEAT`、`SCROLL_SPEED`、`_build_chart()` 里的音符数量和密度。

## 阶段三：电梯怪兽（`Boss/boss_phase.gd`）

- 跳得太烂召唤出电梯怪兽（直接用电梯箱素材 + 代码画的脸和手臂）。
- 两人合力投掷输出，无对抗计分；命中一次 -3 HP，血条在顶部。
- 怪兽攻击轮换：**震地冲击波**（沿地面扩散，跳起躲开）和**丢齿轮**（地上有红叉落点预警）。血越少攻速越快。
- 打倒后播放倒地动画，进入和解对话。
- 可调参数：`boss_hp_max`、`_do_attack()` 里的攻速区间。

## 结构

```text
Stories/Phases/
├── Shared/
│   ├── arena_phase.gd      # 公共基类：移动 / 跳 / 扔 / 眩晕 / HUD / 倒计时
│   ├── character_sprite.gd # 角色显示，切 Assets/Branch/dance.png 的 8 帧
│   ├── retro_sfx.gd        # 程序化 8-bit 音效
│   └── canvas_proxy.gd     # 把绘制转发到精灵上层的小工具
├── Throw/  阶段一
├── Dance/  阶段二
└── Boss/   阶段三
```

每个阶段结束时发 `phase_finished(result: Dictionary)` 信号，串场逻辑在
`Stories/Shared/game.gd` 的 `_run_full_story()`，对话桥段直接改那里的
`Dialogue.entree(...)` 就行。
