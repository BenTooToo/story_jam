# 三阶段玩法（Ver.Mumu 分支）

按队伍草图实现的三个阶段，串在两个锚点之间使用。运行主场景后：

- 按 **5 / 6 / 7** 单独测试某个阶段
- 按 **8** 跑完整流程：吵架 → 扔物大战 → 斗舞 → 召唤电梯怪兽 → 合力打怪 → 和解

## 素材

素材清单和还缺什么见 [`Assets/Branch/素材需求.md`](../../Assets/Branch/素材需求.md)。
代码不直接写素材路径，一律走 `Shared/phase_art.gd` 的登记表：素材在就画素材，
不在就画中性灰占位。**补素材只改那一个文件，玩法代码不用动。**

命中、眩晕、冲击波、落点预警这些特效不走贴图，用 `Shared/phase_fx.gd` 的粒子 + 文字做。
所有渐变统一一条规则：**alpha 两头是 0、中间几乎全程是 1**，出现和消失都不生硬。

角色用三张动作表（都是 4 列 × 2 行、每帧 256×256，上排男 NPC1、下排女 NPC0）：
`dance.png` 跳舞姿势、`扔东西.png` 投掷、`新人物行走.png` 行走循环。
每个姿势对应哪张表的哪几帧，看 `character_sprite.gd` 的 `POSE_CLIP`。

三张表共用同一条落脚线（第 253 行）和同一个胯部中轴（男 117 / 女 113），
都是量素材得出的，所以换动作时脚不会离地、身体不会左右跳。
屏幕身高约 84px（`char_scale = 0.34`），物品也按这个比例显示，和真人大小一致。

**P1 在左边用 NPC0（女），P2 在右边用 NPC1（男）**，和对话框里头像的左右位置一致。

### 舞台效果

- 三个阶段都铺了电梯场景那块**反光地板**（`water.gdshader`，参数照抄 `start.tscn`）。
  它用 screen_texture 把上面的画面倒映下来，靠 `z_index = 5` 排在人物 / 物品 / 粒子之后、HUD 之前，
  所以人物、门、箭头都会映在地上。参数在 `arena_phase.gd` 的 `_setup_floor()`。
  地板顶到脚下（GROUND_Y + 1）；地面那条浅色接触线是开关 `draw_ground_line`，跳舞关掉，人直接站在地板上。
- 阶段二的人物按电梯场景结尾的大小来：`DANCER_SCALE = 0.56`（约 140px 高），电梯箱原尺寸 1.0。
  箭头轨道 `LANE_XS` 整体挪到人物外侧，不和放大后的人物重叠。
- 阶段二有**迪斯科灯**：两层 `light_shafts.gdshader` 交叉打，铺在人物上面、地板下面（地板会倒映光柱）。
  强度每拍冲一下再衰减、角度慢慢左右扫。**颜色不硬切**：每小节算一个新目标色，
  用 0.6 秒 tween 推过去（`_retint()`）；进 / 出副歌时亮度也用一小节 tween 从 0.6 缓到 1.0。
  背景底色（`bg_color`）跟着拍子染一点当前色，目标色同样是 tween 过去的。驱动在 `_drive_disco()`。
- 人物律动：每拍小幅点头（缩放 +4.5%），打中时弹一下（+16%）并闪白，胸口迸一撮该方向颜色的火星。

### 音效

登记在 `phase_art.gd` 的 `SOUNDS`：被砸中时女的在 `girl_hurt1/2` 里随机挑一条、男的放 `man_hurt`
（三个阶段的眩晕都走这条，撞击声压到 −10 dB 给人声让路）；阶段一结束不分输赢放 `cry.mp3`，
只放开头 3 秒然后 2.4 秒淡到听不见。

## 阶段一：扔物大战（`Throw/throw_phase.gd`）

- 90 秒倒计时，中间一扇教室门隔开两人（比人高，跳不过去）。
- 按扔键先播挥臂动画，0.16 秒后东西才真的脱手，对准动作表的出手帧。
- 抛物线**飞行时间固定 1.05 秒、落点精确落在对面出手时的位置**，一定能扔过门。
  弧线高低不靠改初速度（时间和起终点定死后抛物线只有一条），而是**每一发用自己的重力**：
  离门越近重力越大、吊得越高（贴门时几乎垂直抛起），离得远就压平甩过去。
  贴着门（手离门沿 ≤36px）时出手点会抬到门顶之上——举过头顶甩，
  因为从门边 2px 处固定 1.05 秒飞过去在物理上升不过门沿，再大的重力都没用。
  躲的办法是出手后立刻挪位，1.05 秒够跑一段。
- 每次从 14 件物品里随机抓一件，钢笔到马桶都有可能。
- 砸中对面 **+10 分**，被砸中**眩晕 2 秒**（眩晕期间免疫）。
- 空中随机掉落物品，碰到即得分：文具 **+1**、水瓶罐子书筐 **+3**、水桶凳子扫帚马桶 **+5**。
  越大的东西越少见，也越容易碰到（判定范围按物品大小算）。
- 可调参数（Inspector 或代码顶部）：`duration`、`item_interval`。

## 阶段二：舞蹈对决（`Dance/dance_phase.gd`）

- 上下左右音游，跟着 `可爱的小曲.wav` 走：**150 BPM、4/4、主体 56 小节**，共 176 个音符，全在正拍上。
- **前奏先打 8 拍节拍、数 3-2-1**，第一个箭头到判定线的那一刻曲子才响（第 0 拍）。
- 谱面不是随机撒点，是用**图案**拼的（`PATTERNS`：连打 / 两两 / 交替 / 扫过），
  同一图案连着重复几小节再换——重复才好跟，也是"加频率不加难度"的办法：
  4 个一样的箭头连着按，密但简单。连打每 4 个换一次方向，不会同一个键按十几下。
- 段落跟曲式，难度一级级上（`SECTIONS`）：主歌 1-16 半拍只有连打/两两 →
  副歌 17-32 每拍都打但仍只有连打/两两 → 过渡 33-40 半拍加交替 → 副歌2 41-56 图案最全。
  两边谱面完全相同（固定种子，公平）。
- **谱面时间一律以音频播放位置为准**，不是自己累加 delta——累加 90 秒下来会差出好几拍。
  实测 26 秒内和音频的偏差稳定在 0.01 秒以内。

- 谱面打完后**等曲子的 6.95 秒尾巴播完**才进下一段。
- P1 用绿箭头、P2 用红箭头；素材只有朝上一个，四个方向由代码旋转。
- 判定：完美 ±0.08s **+5**；还行 ±0.16s **+2**；±0.22s 之外记一次「烂」。
- **空按算「乱按」**：计一次烂、连击归零、扣 2 分——不然狂点或四个键一起按能白吃所有音符。
  起曲前数拍子阶段随便试键不罚。
  窗口按 150 BPM 收紧过（一拍才 0.4 秒），同轨道音符最小间隔 0.4 秒，保证每个都打得出来。
- 可调参数：`SECTIONS` 的密度、`SCROLL_SPEED`、`music_offset`（整体对不齐时调它）。

## 阶段三：电梯怪兽（`Boss/boss_phase.gd`）

- 跳得太烂召唤出电梯怪兽。**怪兽素材还没到**，现在拿压暗的电梯箱顶着。
- 怪兽会抓水桶凳子扫帚马桶砸人，落点先亮一个红色 **!** 预警。
- 两人合力投掷输出，无对抗计分；命中一次 -3 HP，血条在顶部。
- 怪兽攻击轮换：**震地冲击波**（沿地面扬尘扩散，跳起躲开）和**砸东西**（看地上的感叹号）。血越少攻速越快。
- 打倒后播放倒地动画，进入和解对话。
- 可调参数：`boss_hp_max`、`_do_attack()` 里的攻速区间。

## 结构

```text
Stories/Phases/
├── Shared/
│   ├── arena_phase.gd      # 公共基类：移动 / 跳 / 扔 / 眩晕 / HUD / 倒计时
│   ├── character_sprite.gd # 角色显示，切三张动作表（跳舞 / 投掷 / 行走）
│   ├── phase_art.gd        # 美术素材登记表 + 物品尺寸分值表
│   ├── phase_fx.gd         # 粒子特效和提示文字，渐变规则统一在这里
│   ├── retro_sfx.gd        # 程序化 8-bit 音效
│   └── canvas_proxy.gd     # 把绘制转发到精灵上层的小工具
├── Throw/  阶段一
├── Dance/  阶段二
└── Boss/   阶段三
```

每个阶段结束时发 `phase_finished(result: Dictionary)` 信号，串场逻辑在
`Stories/Shared/game.gd` 的 `_run_full_story()`，对话桥段直接改那里的
`Dialogue.entree(...)` 就行。
