# 三阶段玩法（Ver.Mumu 分支）

按队伍草图实现的三个阶段，串在两个锚点之间使用。运行主场景后：

- 按 **5 / 6 / 7** 单独测试某个阶段
- 按 **8** 跑完整流程：吵架 → 扔物大战 → 斗舞 → 召唤电梯怪兽 → 合力打怪 → 和解

## 素材

素材清单和还缺什么见 [`Assets/Branch/素材需求.md`](../../Assets/Branch/素材需求.md)。
代码不直接写素材路径，一律走 `Shared/phase_art.gd` 的登记表：素材在就画素材，
不在就画中性灰占位。**补素材只改那一个文件，玩法代码不用动。**

角色用三张动作表（都是 4 列 × 2 行、每帧 256×256，上排男 NPC1、下排女 NPC0）：
`dance.png` 跳舞姿势、`扔东西.png` 投掷、`新人物行走.png` 行走循环。
每个姿势对应哪张表的哪几帧，看 `character_sprite.gd` 的 `POSE_CLIP`。

三张表共用同一条落脚线（第 253 行）和同一个胯部中轴（男 117 / 女 113），
都是量素材得出的，所以换动作时脚不会离地、身体不会左右跳。
屏幕身高约 84px（`char_scale = 0.34`），物品也按这个比例显示，和真人大小一致。

**P1 在左边用 NPC0（女），P2 在右边用 NPC1（男）**，和对话框里头像的左右位置一致。

## 操作

| 玩家 | 移动 | 跳 | 扔 | 跳舞 |
| --- | --- | --- | --- | --- |
| P1（左，NPC0 女） | A / D | W | F | WASD |
| P2（右，NPC1 男） | ← / → | ↑ | `/`（或小键盘 0） | 方向键 |

## 阶段一：扔物大战（`Throw/throw_phase.gd`）

- 90 秒倒计时，中间有障碍物隔开两人（跳不过去）。
- 按扔键先播挥臂动画，0.16 秒后东西才真的脱手，对准动作表的出手帧。
- 抛物线自动瞄准对面当前位置；站得离墙太近会被墙挡住，需要拉开距离起高抛。
- 每次从 14 件物品里随机抓一件，钢笔到马桶都有可能。
- 砸中对面 **+10 分**，被砸中**眩晕 2 秒**（眩晕期间免疫）。
- 空中随机掉落物品，碰到即得分：文具 **+1**、水瓶罐子书筐 **+3**、水桶凳子扫帚马桶 **+5**。
  越大的东西越少见，也越容易碰到（判定范围按物品大小算）。
- 可调参数（Inspector 或代码顶部）：`duration`、`item_interval`。

## 阶段二：舞蹈对决（`Dance/dance_phase.gd`）

- 上下左右音游，96 BPM，两边谱面完全相同（固定种子生成，公平）。
- P1 用绿箭头、P2 用红箭头；素材只有朝上一个，四个方向由代码旋转。
- 判定：完美 ±0.11s **+5**；还行 ±0.24s **+2**；再宽或漏过记一次「烂」。
- 节拍、判定音效都是代码生成的 8-bit 音，之后可以换成真音乐（改 `BEAT` 对上 BPM 即可）。
- 可调参数：`BEAT`、`SCROLL_SPEED`、`_build_chart()` 里的音符数量和密度。

## 阶段三：电梯怪兽（`Boss/boss_phase.gd`）

- 跳得太烂召唤出电梯怪兽。**怪兽素材还没到**，现在拿压暗的电梯箱顶着。
- 两人合力投掷输出，无对抗计分；命中一次 -3 HP，血条在顶部。
- 怪兽攻击轮换：**震地冲击波**（沿地面扩散，跳起躲开）和**丢齿轮**（地上有红叉落点预警）。血越少攻速越快。
- 打倒后播放倒地动画，进入和解对话。
- 可调参数：`boss_hp_max`、`_do_attack()` 里的攻速区间。

## 结构

```text
Stories/Phases/
├── Shared/
│   ├── arena_phase.gd      # 公共基类：移动 / 跳 / 扔 / 眩晕 / HUD / 倒计时
│   ├── character_sprite.gd # 角色显示，切三张动作表（跳舞 / 投掷 / 行走）
│   ├── phase_art.gd        # 美术素材登记表 + 物品尺寸分值表
│   ├── retro_sfx.gd        # 程序化 8-bit 音效
│   └── canvas_proxy.gd     # 把绘制转发到精灵上层的小工具
├── Throw/  阶段一
├── Dance/  阶段二
└── Boss/   阶段三
```

每个阶段结束时发 `phase_finished(result: Dictionary)` 信号，串场逻辑在
`Stories/Shared/game.gd` 的 `_run_full_story()`，对话桥段直接改那里的
`Dialogue.entree(...)` 就行。
