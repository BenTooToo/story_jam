# 爱心下降弹幕关卡

运行项目会从完整剧情开场自动开始。单独预览弹幕关卡可运行 `Stories/BulletHell/bullet_hell.tscn`。

- 方向键 / WASD：移动；Shift：慢速移动。
- 完成四段下降，让女人头像下降到男人头像处即可获胜。每段第 8 秒停产，至少持续 10 秒，并等剩余障碍自然离场再进入下一段。
- 碰撞三次失败，每次受伤后有 1.25 秒无敌时间；场地下方三个爱心表示剩余生命。
- 结算后 R 重试；Esc 返回原测试场景。

开场：黑屏 0.8 秒 → 呼吸淡入 2 秒 → 静止 0.7 秒 → 三次快速抖动（每次 0.4 秒，共 1.2 秒） → 心心1与红色火花同时出现。
失败：停止弹幕 → 爱心按原节奏抖两次 → 第二次结束瞬间消失并播放同款红色火花。
头像使用原人物头像素材的头部正方形 AtlasTexture 裁剪；不生成或修改原贴图。

回归验证：Godot --headless --path . --log-file .godot/bullet-test.log --script Tests/bullet_hell_test.gd


关卡阶段（每段至少 10 秒）：四周随机向中央区域发射自转陨石 → 上升砖块（速度 74、缺口 96）→ 红色区域闪烁 0.5 秒，长方形从外侧平移进入并原路返回 → 加速砖块（速度 90、缺口 58，最后两道缩到 18，红心可见宽度 12）。阶段切换等待上一阶段障碍自然离场，不强制清除。长方块前两波往返，最后两波分别为 6 块和 10 块，各留两条中央安全通道，直接穿场并在完全飞出屏幕后释放。红色预警覆盖从来源边框到目标的路径，边框箭头标明方向。


陨石为较大的不规则中空椭圆，双层轮廓并持续自转；绘制按场地矩形裁切，离开边框后仍运动，越过额外 64 像素清理范围后释放。

女人头像使用独立时钟轻摆，进度等待清场时也继续运动。失败后先渐暗到黑屏，再逐字显示红字“你的智商低低的，还蛮可爱”；文字结束一秒后，下方小字“按r键重新开始”缓慢闪烁。胜利只渐暗到黑屏。
