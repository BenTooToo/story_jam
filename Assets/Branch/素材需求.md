### 音乐

`可爱的小曲.wav` —— 阶段二的曲子。**150 BPM、4/4、主体 56 小节**，曲式：

| 小节 | 段落 | 谱面 |
| --- | --- | --- |
| 1-16 | 主歌 | 半拍，只有连打/两两，1.25 个/秒 |
| 17-32 | 副歌 | 每拍都打，仍只有连打/两两，2.5 个/秒 |
| 33-40 | 过渡 | 半拍，加入交替，1.25 个/秒 |
| 41-56 | 第二次副歌 | 每拍都打，连打/两两/交替/扫过，2.5 个/秒 |

音符全在正拍上、没有八分切分；同一图案连着重复几小节，连打每 4 个换方向。
曲子响之前先打 8 拍节拍数 3-2-1，第一个箭头到判定线那一刻才起曲。

全曲 96.15 秒 = 60.1 小节，56 小节主体之后还有 **6.95 秒尾巴**，
谱面打完会等它播完再进下一段。

分析过音频：0 秒就出声，起音全部落在 0.4 秒的网格上，所以 `music_offset` 是 0。
换曲子或者觉得整体偏早/偏晚，只调 `dance_phase.gd` 的 `music_offset` 一个数。

文件是 24bit WAV（25MB），Godot 导入时按 QOA 压了。要进一步减小发布包的话
可以转成 OGG，代码会自动认（`_find_music()` 会扫目录）。

## 特效改用粒子，不再需要贴图 ⚙️

以下原本列在清单里的，现在全部用**粒子特效 + 文字**做，见 `Stories/Phases/Shared/phase_fx.gd`：

| 原素材需求 | 现在的做法 |
| --- | --- |
| 命中特效 | 砸中就在落点迸一撮火星，自己淡完自己清理 |
| 眩晕星星 | 头顶一圈绕着转的黄色火花，跟着角色一起动 |
| 冲击波 | 沿地面一路扬起的尘土，拖尾短，一眼能看出波前在哪 |
| 落点预警 | 地上弹一个红色 **!** ＋往上飘的火星 |
| 齿轮 | 怪兽直接抓水桶凳子扫帚马桶砸回来，用现成的物品素材 |

**所有渐变统一一条规则**：alpha 在最开头和最结尾是 0，中间几乎全程是 1，
所以出现和消失都是渐变的，不会硬闪。文字也一样淡入淡出＋轻微弹跳。
倒计时数字、横幅、掉落物快消失时的闪烁也都改成了渐变。

## 通用规格

- 游戏分辨率 **640×360**，像素风，纹理过滤 Nearest。角色屏幕身高约 **84px** 作参照。
- 角色表是 3 倍超采样（256px/帧 显示 84px），所以上面「建议素材尺寸」都按屏幕尺寸 3 倍给。
- 透明背景 PNG，多帧横向排一行。画布带透明边没关系，登记表里记内容框就行。
